# Créditos das fotografias

Todas as seis fotografias mostram os locais indicados, conforme descrição e identificação no Wikimedia Commons. São registros de arquivo, não uma garantia do estado atual. Nenhuma dessas seis imagens permanece ilustrativa. Arquivos redimensionados para até 1280 pixels e convertidos para JPEG; a interface pode recortar a exibição.
